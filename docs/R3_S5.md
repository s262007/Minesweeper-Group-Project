## Animation

```text
sbt "Test/runMain minesweeper.AutoPlayFrames"    # docs/figures/autoplay_frames.txt
python scripts/autoplay_gif.py                   # docs/figures/autoplay.gif (Pillow)
```

**Choosing the game.** `AutoPlayFrames` searches the model games for the first Beginner game (9x9, 10 mines) that the v1 player wins after exactly one guess, with at least 6 decision boards. That is game 0, seed 12346.

**Recording.** It then plays that game on the simulated `MinesweeperCore`, in lockstep with the golden model, and checks that the record equals the model's. The game has 30 commands: the new game, the first click, 27 safe hints and one guess. It ends in a win. The run took 35 minutes, because the default simulator is slow at 9x9.

**Drawing.** The Python script draws one frame per command:
- safe hints in green, mine hints in red;
- the last move framed in orange;
- the move, the state and the mines left above the grid.

The frames file is committed, so the GIF can be redrawn without sbt.

## Fresh clone check

On 10 November 2026, the branch was cloned into an empty folder (`git clone --branch r3/s5-docs`), with no build output. The README commands below were run there, in one sbt session of 4 min 44 s including the first compilation:

| Command | Result |
|---|---|
| `sbt "testOnly minesweeper.ContractTest minesweeper.AutoPlayTest"` | 13/13 tests pass (12 contract tests and the short AutoPlay run) |
| `sbt "Test/runMain minesweeper.PlayConsole 6 6 5 1 --script \"r 2 2; a; q\""` | Plays on the simulated Core. The reveal took 70 cycles. `a` answered "No safe hint on a hidden cell", which is correct for that board |
| `sbt "Test/runMain minesweeper.AutoPlay 20 0 results/quick.csv"` | Wrote the CSV: 20 model games per row, no hardware games, 5 s |
| `sbt "runMain minesweeper.EmitNexys4Top"` | Wrote `generated/nexys4/top/Nexys4Top.sv` (11.6 MB) in 44 s |
| `python scripts/autoplay_gif.py docs/figures/autoplay_frames.txt <out>.gif` | Redrew the 30-frame GIF from the committed frames |

Not run on the fresh clone:
- **The whole fast suite and the z3 proofs.** CI runs them on every pull request from a fresh checkout. z3 is not installed on this laptop.
- **The slow tests.** They take hours.
- **The full AutoPlay run (32 min) and `AutoPlayFrames` (35 min).** Both were run in the working copy for this branch.
