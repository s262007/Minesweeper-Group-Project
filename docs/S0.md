## Working in IntelliJ

Open the repository as an sbt project. The build uses sbt 1.12.13, Scala 2.13.16,
Chisel 6.7.0 and ChiselTest 6.0.0, the same stack as the course labs 6-8.
Use one JDK 17 or later (temurin-17 or temurin-25 both pass) for both the Project
SDK and sbt JVM. Keep the repository's sbt version pin. CI uses JDK 17.
No separate launcher or Scala installation is required for the IntelliJ workflow.

## What the shells establish

S0Stubs.scala belongs to R1. Replace its bodies during R1-S1 and R1-S2;
do not introduce duplicate class definitions when splitting it into module files.
The shells refuse commands, provide no settled snapshot or deductions, and keep
TX idle. Board outputs are placeholders, not the configured reset game state.
FpgaTop checks the logical core/bridge connection only. UART byte hardware and
R2 engines are not instantiated, so this is not the complete team skeleton or
physical FPGA integration. S0SmokeTest verifies RTL emission and these limits.
